# Dashkit Full Package Explanation

## What Dashkit is
Dashkit is a Laravel package that acts as a dashboard engine.
It provides dashboard authentication, layout, widgets, page generation, module generation, installer, and full uninstall/rollback support.

## Core idea
Dashkit keeps package logic in `packages/dashkit`, but generates project-level artifacts in your app (global scope) so your app owns pages, modules, models, routes, and migrations.

## Main capabilities
- Dashboard routing with root dashboard home and configurable content prefix/middleware
- Login/logout flow for dashboard access
- Sidebar + topbar UI layout
- Widget registry with token resolution (example: `users_count`)
- Interactive installer (`dashkit:install`)
- Preset-aware installation (`default`, `ecommerce`, `crm`)
- Page scaffolder (`dashkit:make-page`)
- Module scaffolder (`dashkit:make-module`)
- Preset switcher (`dashkit:switch-preset`)
- Controlled uninstall with preview/backup (`dashkit:uninstall`)

## Package architecture
- Service Provider: bootstraps config, routes, views, publish tags, commands
- Commands: install, uninstall, upgrade, switch-preset, make-page, make-module
- Controllers: dashboard and auth controllers
- Services: widget registry
- Support: artifact manifest tracking generated files/routes

## Global artifacts generated by Dashkit
Dashkit can generate and track files in app scope:
- `resources/views/dashkit/pages/*`
- `resources/views/dashkit/modules/*`
- `app/Models/*`
- `app/Http/Controllers/Dashkit/*`
- `database/migrations/*`
- `routes/web.php` route blocks appended by Dashkit commands

## URL model
- `/` => dashboard home
- `/login` => dashboard login
- `/dashboard/<slug>` => generated pages and generated modules

## What uninstall removes
When confirmed, uninstall can remove:
- Published config/views/assets
- Installer changes (tracked rollback state)
- Generated pages/modules/models/controllers/migrations tracked in manifest
- Dashkit-generated route entries in `routes/web.php`
- Dashkit guest redirect and related `.env` installer keys

If the package is still required in the project, uninstall keeps provider registration so Dashkit commands remain available.

## Tracking files used by Dashkit
- Installer rollback state: `storage/app/dashkit/install-state.json`
- Generator artifact manifest: `storage/app/dashkit/artifacts.json`
- Optional uninstall backups: `storage/app/dashkit/uninstall-backups/<timestamp>/`
